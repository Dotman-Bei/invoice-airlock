### Reaching a Switch server: the facts for C1-C3

The rows stay **hard** as the user set them. These facts bear on how to clear them; choosing a route is the user's decision.

- **Docker Desktop's published minimum is not met.** Docker's Windows install page lists Windows 11 version 23H2, build 22631 or higher. This machine is build 21996. Not attempted, so whether it installs or runs anyway is unknown. Hardware virtualization: `HypervisorPresent` is true and the firmware flag reads false, which is inconclusive.
- **Switch's docs disagree on whether Docker is required.** The quickstart and "Choose how to run Switch" say Docker. The Console 0.40.0 changelog announces a local server without Docker, and Troubleshooting says only the bundled Mattermost needs Docker. Without it the server has no chat app, so Slack, Discord or Telegram must be connected instead.
- **That native path is where Windows failures are reported.** #1335 (open, Console v0.40.1, server v0.31.0) is `initdb.exe` exiting with 3221226505. A maintainer's interim advice there was to run Console in a Linux VM. This machine has no PostgreSQL install and has the VC++ x64 runtime v14.42, the two causes that thread tested first; neither explained that reporter's failure.
