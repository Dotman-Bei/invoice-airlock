# Wispr Flow: requirements for Code with Wispr

Scope: what the scorecard needs and how to get it. Fetched 2026-11-04. Source IDs resolve in [../INDEX.md](../INDEX.md).

## What the track asks for

Speak prompts to the coding agent, room instructions and the README through Wispr Flow rather than typing them. Add the usage scorecard when submitting. The best project built by voice wins `$500`. [S1]

## Getting the scorecard

1. **Install.** Use the event's link, which includes 1 month of Wispr Flow Pro free: `https://wisprflow.ai/?promo_code=WEMAKEDEVS`. [S1]
2. **Dictate while building.** Start now, because the card reflects what has been dictated.
3. **Capture.** Desktop app, left sidebar: **Insights**, then the **Your usage** tab. [S12]
4. **Export.** WMD's earlier Wispr Challenge form says to use **Share** on that tab and upload the card. [S10] This event's page asks for a screenshot from Insights. [S1] Wispr's help article does not mention Share, so confirm the button when the app is installed.
5. **Submit.** This event's form does not exist yet. See [../event.md](../event.md) question 4.

## What the card shows

From Wispr's help article, updated about 19 days before fetch. [S12]

- Words per minute
- Fixes made by Flow
- Total Words Dictated, which is **lifetime** and includes mobile
- Desktop usage by category and app
- Activity heatmap with streaks

Stats refresh at app start, at sign-in, about hourly, and after a dictation. Insights is on Mac and Windows desktop only.

**Timing evidence.** Total Words Dictated is lifetime rather than event-scoped, and this event states no minimum word count or date window. Another Wispr event measured words dictated during its challenge window, and confirmed winners' numbers with Wispr. [S10] Whether this event does the same is unknown.

## Platform requirements

Wispr's docs ask for Windows 10 or 11 on x64, with 8 GB RAM recommended, about 200 MB free, and a working microphone. ARM Windows is unsupported. [S13] This machine's Insider build 21996 was not tested. Current state: see tollgate row C5.

## Gaps

- **Scoring:** no criteria beyond "best project built by voice". The earlier Wispr event said judges look at how much writing went through Flow. [S10] That is a signal, not a rule for this event.
- **Whether the free month is required:** not stated. Wispr's Basic plan has a weekly word cap and Pro is listed as unlimited, per a search summary of Wispr's plan pages (secondary, not read directly).
